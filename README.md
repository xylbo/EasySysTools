


# EasySysTools    README.md 

EasySysTools是一套工具软件集合(含自制工具和技巧),

对于(重度系统安装爱好者)和(重度运维爱好者)来说,

## 解决了如下痛点:

1.重复设置.系统某些设置,

2.安装过程中,需要满世界的找软件.


3.这套工具可以帮你,,快速的进入使用状态.


## EasySysTools分成3个层次,用目录代替(当然你也可以细化成更多)

100.:lite.状态,快速进入使用状态.包含(备份,系统安装,设置优化,使用基础app)

200.:full.进阶优化设置,运维等.

900.:使用者自己的数据(文件,软件等),可以自己添加.









对于捐赠者,我有更多的软件工具,包含自制工具,以及使用技巧与你分享.


特别注意:需要安装 everything 软件,并在其中这个位置打√(工具-选项-常规-支持URL协议)
