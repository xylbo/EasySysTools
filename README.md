

#  EasySysTools  README.md


EasySysTools是一套工具软件集合(含自制工具和技巧),

对于(*重度.系统安装.爱好者*)和(*重度.运维.爱好者*)来说,

## 解决了如下痛点:

1.重复设置.系统某些设置,

2.安装过程中,需要满世界的找软件.


3.这套工具可以帮你,,快速系统安装.进入使用状态.


## EasySysTools分成3个层次,
用目录代替(当然你也可以细化成更多)

100.:lite.状态,快速进入使用状态.包含(备份,系统安装,设置优化,使用基础app)
		(<a href="https://xylbo.github.io/EasySysTools/100.lite.100.200.900..lengbo.zip">下载</a>	)

	200.:full.进阶优化设置,运维等.

	900.:使用者自己的数据(文件,软件等),可以自己添加.



## 特点:

1.工具少而精,挖掘Windows自带功能,快速进入状态

2.结构清晰.大纲式.
